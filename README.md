## 零

之前用 `javascript` 写的略微有些混乱，由于基本没借助框架，所以添加功能要自己写很多东西。同时还有一些细节没注意好，比如说错误处理之类的，而且有时候为了方便而，直接把 QQ 号之类的（可能敏感的）数据写进了代码里面，我现在认为这是不优雅的。

所以我打算重新写一遍，也顺带把一些小功能补上。这次我打算直接用 rust 写了，因为看起来更优雅一些。

不过有一些画图之类的库可能要重新研究了，慢慢写吧。

## 一

bot 主要是一些赤石小功能，小众音游功能。所有功能可对于每个群单独添加，可用指令管理，指令都是以 `$` 开头的。

1. 表情回复：发出的消息内容里面，如果存在某个表情，那么就自动贴一个上去。

2. 表情管理：有时候贴出来的表情有滚木，我就希望删掉；或者是某个之前没被当作表情的表情，我就希望添加。

3. 更多功能绝赞添加中。
